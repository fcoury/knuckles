# PG1316S 3D model

`PG1316S.step` is the original Kailh CAD assembly shared by Mike Holscher
with Kailh's permission:

https://github.com/mikeholscher/zmk-config-mikefive/tree/main/files/footprint-and-cad

The switch dimensions are reported to be accurate. The keycap exterior in
the assembly is slightly undersized; use the project's keycap clearance
outline rather than this model for case clearances.
